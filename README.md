# void

**Экспериментальный векторный редактор с аппаратным ускорением**

![void-demo](https://github.com/nlkli/void/blob/main/assets/void-demo.gif)

Первая попытка реализации минималистичного графического редактора для составления схем и рисования из простых графических примитивов. Проект задумывался как инструмент для визуального проектирования. like excalidraw.

**Технологии:**
- **Vello** — GPU-ускоренный рендеринг векторной графики
- **winit** — кроссплатформенная оконная система

**Возможности:**
- Базовые операции над фигурами (создание, перемещение, выделение, удаление, трансформация)
- Масштабирование и навигация по холсту
- Управление слоями (перемещение, изменение порядка)
- Горячее обновление конфигурации окна и рендеринга
- ...

**Статус:**
Проект временно заморожен из-за высокой сложности и нехватки времени. Код носит экспериментальный характер и не имеет чёткой архитектуры — это скорее песочница для изучения возможностей Vello и подходов к построению графических редакторов, чем готовый продукт.
